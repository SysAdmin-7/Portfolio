prérequis :
- il faut une machine linux avec SSH d'installer dessus sinon voir [[01_Installation_SSH]]
- avoir l'IP de la machine, le nom d'utilisateur et le mot de passe de l'utilisateur voir [[01_Commande_de_base_linux]]

sur Windows :
- aller dans le cmd (appuyer sur les touches Windows + r et écrire cmd puis appuyer sur entrée)

- dans le cmd :
```bash
ssh nom_utilisateur@ip_machine
#saisir le mot de passe
#demande pour la 1ère connexion si on est sûr écrire yes
```

> [!warning]
> important : 
> - il ne faut pas faire de faute d'orthographe sinon ça ne marche pas
