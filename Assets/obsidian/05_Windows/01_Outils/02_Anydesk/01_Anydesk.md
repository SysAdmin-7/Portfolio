Anydesk sert a prendre le contrôle du pc a distance.

- il est un outil parfait pour le support de proximité (Helpdesk). Pour l'administration d'infrastructures serveurs, privilégier des protocoles sécurisés comme SSH (clés privées) ou RDP via un tunnel VPN.

# 📖 Tutoriel AnyDesk

> **Objectif :** Se connecter à un autre ordinateur ou laisser quelqu'un se connecter au mien pour une assistance à distance.

---

#  Installation

1. Télécharger AnyDesk depuis le site officiel.
2. Lancer le programme.
3. Installer AnyDesk (option recommandé) ou l'utiliser sans installation.

✅ Une fois ouvert, une adresse AnyDesk apparaît.

---

# 🖥 Comprendre la fenêtre

## Mon adresse

C'est le numéro affiché en haut.

Exemple :

```
123 456 789
```

 C'est ce numéro que je donne à la personne qui doit accéder à mon ordinateur.

---

## Adresse distante

C'est l'endroit où je tape le numéro de l'autre ordinateur.

Exemple :

```
987 654 321
```

Puis je clique sur **Se connecter**.

---

# 🔗 Se connecter à un autre PC

1. Ouvrir AnyDesk.
2. Demander l'adresse AnyDesk de la personne.
3. Entrer le numéro dans **Adresse distante**.
4. Cliquer sur **Se connecter**.
5. Attendre que la personne accepte.

Si elle accepte :

 Je vois son écran.

---

# 🛠 Se faire dépanner

Si quelqu'un doit m'aider :

1. Ouvrir AnyDesk.
2. Lui donner mon adresse AnyDesk.
3. Attendre sa demande.
4. Cliquer sur **Accepter**.

L'autre personne peut maintenant voir mon écran.

---

# 🔒 Les autorisations

Avant d'accepter, je peux choisir :

- ☑ Voir mon écran
- ☑ Contrôler le clavier
- ☑ Contrôler la souris
- ☑ Copier des fichiers
- ☑ Utiliser le presse-papiers

Je peux décocher ce que je ne souhaite pas autoriser.

---

#  Transfert de fichiers

Deux méthodes :

## Méthode 1

Glisser-déposer un fichier entre les deux ordinateurs.

## Méthode 2

Utiliser :

**Menu → Transfert de fichiers**

---

# 💬 Chat

Pendant la connexion :

Menu → **Chat**

Permet de discuter sans téléphone.

---

#  Copier / Coller

Le copier/coller fonctionne entre les deux ordinateurs.

Exemple :

- Copier un texte sur le PC distant.
- Coller sur mon PC.

---

# ⚙ Paramètres utiles

## Accès sans surveillance

Permet de se connecter sans que quelqu'un accepte.

Configuration :

Paramètres → Sécurité

Puis :

- Activer l'accès sans surveillance.
- Choisir un mot de passe solide.

 À utiliser uniquement sur un ordinateur personnel.

---

## Modifier le nom du PC

Paramètres → Interface

Permet de remplacer le numéro par un nom plus facile à reconnaître.

Exemple :

- PC Bureau
- PC Maison
- Serveur

---

#  Fin de la connexion

Pour arrêter :

Cliquer sur :

**Déconnecter**

ou simplement fermer la fenêtre.

---

#  Bonnes pratiques

 Donner son adresse uniquement à une personne de confiance.

 Fermer AnyDesk lorsque je n'en ai plus besoin.

 Utiliser un mot de passe fort pour l'accès sans surveillance.

 Vérifier les autorisations avant d'accepter une connexion.

---

#  Problèmes fréquents

## Impossible de se connecter

Vérifier :

- Internet fonctionne.
- Le numéro AnyDesk est correct.
- AnyDesk est ouvert sur l'autre ordinateur.

---

## Écran noir

- Redémarrer AnyDesk.
- Vérifier les autorisations.
- Redémarrer l'ordinateur si nécessaire.

---

## Impossible de contrôler la souris

L'autre personne doit autoriser :

- Contrôle du clavier
- Contrôle de la souris

---

# ⌨ Raccourcis utiles

| Action | Description |
|---------|-------------|
| F11 | Plein écran |
| Ctrl + Alt + Suppr | Envoyer au PC distant |
| Ctrl + C / Ctrl + V | Copier / Coller |

---

#  Pense-bête

## Pour aider quelqu'un

1. Demander son adresse AnyDesk.
2. Entrer l'adresse.
3. Cliquer sur **Se connecter**.
4. Attendre l'acceptation.

---

## Pour recevoir de l'aide

1. Ouvrir AnyDesk.
2. Donner mon adresse.
3. Accepter la connexion.
