- changement d'emplacement :
```bash
cd nom_dossier #changer de dossier
cd ../ #revenir en arrière dans l'arborésence des dossier
```

- afficher les fichier & dossier dans le terminal :
```bash
dir #affiche dossier & fichier
```

- créations de fichier :
```bash
touch nom_fichier #crée le fichier avec le nom donner en txt
touch nom_fichier.extention # crée le fichier avec le nom et l'extention donnée
```

- éditeur de texte : 
```bash
nano nom_fichier #ouvre le fichier pour édité de dans 
```

- avoir son IP :
```bash
ip a #affiche l'ip de tout les carte réseau du pc
```

> [!warning] information
> - pour plus d'information sur sudo voir [[02_Permission_administrateur]]

- faire les mise a jours de paquet :
```bash
sudo apt update #met a jours les paquets
```

- mettre a jours la version de l'OS : 
```bash
sudo apt upgrade #met a jours l'OS
```

- double commande :
```bash
commande_1 && commande_2 #une double commande est possible en mettent && entree les 2 commandes de ce fait on peut en faire 2 sur la même ligne et elle s'éxécute l'une après l'autre.
```

- savoir qui on est (quel utilisateur) :
```bash
whoami
```

- création de dossier :
```bash
mkdir nom_dossier
```

- suppression de dossier :

```bash
rmdir nom_dossier
```
