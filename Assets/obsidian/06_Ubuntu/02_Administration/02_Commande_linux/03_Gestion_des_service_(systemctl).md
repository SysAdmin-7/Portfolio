```bash
sudo systemctl status nom_service #sert a voir l'état du service (en cours, a l'arrêt ... etc)
sudo systemctl stop nom_service #sert a arréter le service
sudo systemctl start nom_service #sert a lancé le service
sudo systemctl enable nom_service #sert a démaré le service au démarage
sudo systemctl restart nom_service #sert a redémarré totalement le service
sudo systemctl reload nom_service #sert a redémarré le service sans coupé la connexion
```
