- il faut être dans le même dossier que le fichier (cd) ou noté le chemin (chemin/complet/nom_fichier.sh)
- rendre exécutable un script.sh :

```bash
sudo chmod +x nom_script.sh #chmod +x donne le droit de pouvoir exécuté le fichier visée
```

- si besoin plus d'information sur chmod voir [[04_Permission_des_fichiers]]

- pour exécuter le fichier il faut être dans le même dossier avec le terminal puis écrire :
```bash
./nom_fichier.sh #le ./ veut dire dans le dossier actuel et vue que l'on appel le script auto il s'exécute
```
