- permission sudo :
```bash
sudo suite_commande #pour exécuté en sudoeur/admin et demande le mot de passe pour confirmation
```

- permission root (dieu) :
```bash
su - #demande le mot de passe root et après a tout les pouvoir même supprimer tout l'OS
```

- sortir du mode root : 
```bash
exit #quand en mode root permet d'en sortir
#ou appuyer sur les touches ctrl + d
```

- pour ubuntu :
```bash
sudo -i #pour passer en root sur ubuntu
```
