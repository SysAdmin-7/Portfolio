> [!important]
> Partie 1 : installation avec Driver

> [!Méthode]
> 
> - installer le driver sur internet le site de HP support 
> - choisir le pilote sans installer dans notre cas il feras largement l'affaire
> - extraire le dossier télécharger en double cliquant sur le prog installer (le dossier va a la racine du disque tout seul)
> - Ouvre **Panneau de configuration (Windows + r écrit control)> Périphériques et imprimantes**.
> - Clique sur **Ajouter une imprimante**.
> - Sélectionne **L'imprimante que je veux n'est pas répertoriée**.
> - Choisis **Ajouter une imprimante à l'aide d'une adresse TCP/IP.
> - Entre l'adresse IP de l'imprimante.
> - Quand Windows demande le pilote :
>     - Clique sur **Disque fourni...**
>     - Parcours jusqu'au dossier contenant le fichier `.INF` du pilote HP. ( a la racine du C:)
>     - Sélectionne le pilote **HP**
> - click droit
> - propriété de  l'imprimante 
> - port
> - configuré le port 
> - désactivé l'état SNMP

> [!info]
> - si il veut pas modifier re tourner dans général en bas a gauche modifier les propriété
